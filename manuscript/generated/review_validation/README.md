# Targeted revision analyses and calibration refresh (14 November 2026)

Current WiNN benchmark derivatives use development version 0.1.7.9999 (package commit `ab4969792c98bd86208a28a4e83b7a69e204b9fc`) with permutation maxT drift calibration. Comparator outputs, baseline fits and design audits are unchanged. New calibration experiments and the unchanged-function audit are in `../calibration_revision/`, with scripts and frozen source under `scripts/calibration_revision/`.

The targeted gate and preparation simulations in this directory remain historical controls: they source the exact frozen WiNN 0.1.6 implementation under `scripts/targeted_validation/source_snapshot/winn/`. The legacy null-gate results are compared explicitly with the new gate; MAD/PQN-only experiments are unaffected by this revision. Source checksums and session details are provided.

From the manuscript directory:

```sh
Rscript scripts/targeted_validation/run_targeted_biology_audit.R
Rscript scripts/targeted_validation/verify_null_gate_calibration.R
```

The first script regenerates scheduled-QC, 100-seed drift/batch gate, and 100-seed biological MAD/PQN stress outputs. The second independently checks the global-null drift gate at 1,000 seeds for each segment length and verifies agreement with base R `Box.test`. It compares raw and MAD-prepared inputs. These scripts do not alter the correction implementation. The 5 MB feature-level p-value sample is regenerated by the first script rather than duplicated in this manuscript checkout; aggregate and seed-level results are supplied.

The identity-retrieval exports retain the original query-weighted point estimates and correct the 2,000 paired identity-bootstrap draws to weight each resampled identity by its eligible query count. The original identity-weighted intervals are retained in explicitly named `_before_query_weighting` audit files; they are not the current uncertainty estimates. Clinical per-identity sufficient statistics were recovered exactly from the archived bootstrap series and checked against every original draw and the raw matrix, without exporting identity rows; for both the 0.1.6 and permutation-calibration refreshes they were read directly from each new derivative run, which kept them on the analysis machine. `batchcorr_identity_retrieval_paired.csv` is a separate new identity-balanced 5,000-draw sensitivity analysis, with a different estimand; it is not substituted into the manuscript’s frozen endpoint.

Prepared design CSVs are aggregate audits of the benchmark’s actual prepared metadata. No private clinical biological identifiers or raw clinical matrices are included. Clinical phenotypes are unavailable; their balance was not audited. Same-feature effect summaries compare with raw input descriptively and do not treat features as independent biological replicates.

The historical benchmark refresh and targeted implementation checks used the frozen WiNN 0.1.6 build (source tarball SHA-256 e40a2c3fd709f11a456ac3721379da3549e89c619e5a164743e203fe1e9be7ab), which corrects the mgcv smoother calls that made earlier versions fall back to LOESS; the permutation-calibrated development build retains these corrected smoother calls. Only WiNN outputs were recomputed for 0.1.6: competitor and Raw outputs, the baseline fits and the design audits are reused unchanged from the validated 0.1.4 release, and the 0.1.4 versions of every refreshed file are archived outside this checkout. Corrected QC-RFSC results replace the previous adapter in simulation Figure 2, Figure S3 and Table S4. Table S26 reports all five completed empirical point evaluations: held-out reference precision, raw-restored feature counts, residual acquisition-order GAM deviance and categorical batch association, with replicate-profile ICC/Pearson for BatchCorr and clinical data. The complete 84-row point export is also included. Old-adapter values are excluded from publication tables and panels; original values remain in the audit files and Git history. Validation is recorded in `qcrfsc_completed_integration_checks.csv`; aggregate results and original completion records are under `euler_completed/`.

The portable official Wehrens baseline adapter and unchanged GPL-licensed source are under `scripts/nearest_baseline/`. The completed comparisons include exact ten-seed simulation truth (Table S27), query-weighted identity retrieval (Table S23) and descriptive empirical feature effects (Table S28), with the empirical validation checks in `baseline_biology_validation_checks.csv` (91 in the current calibration refresh, which reuses the unchanged baseline rows and draws). Prepared input matrices must be supplied separately with `--input-root`; the public analysis repository supplies their preparation command. The QC-RLSC diagnostic is under `scripts/benchmark_revision/`, with aggregate warnings, reference coverage and public representative traces in files beginning `mtbls79_qcrlsc_` in this directory. Neither workflow bundles raw clinical inputs.
