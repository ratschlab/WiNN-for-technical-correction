# Targeted validation and completed QC-RFSC analyses (22 November 2026)

These outputs retain the archived multi-method benchmark and identify the current QC-RFSC replacements explicitly. The chronological RFSC refits and 18 conditional bootstrap endpoints are documented in `scripts/benchmark_revision/README.md`; superseded uncertainty is retained only under `archive_boundary_relocation_20261122/`. The targeted gate and preparation simulations source the exact frozen WiNN 0.1.6 R implementation included under `scripts/targeted_validation/source_snapshot/winn/`. Source checksums and session details are provided.

From the manuscript directory:

```sh
Rscript scripts/targeted_validation/run_targeted_biology_audit.R
Rscript scripts/targeted_validation/verify_null_gate_calibration.R
```

The first script regenerates scheduled-QC, 100-seed drift/batch gate, and 100-seed biological MAD/PQN stress outputs. The second independently checks the global-null drift gate at 1,000 seeds for each segment length and verifies agreement with base R `Box.test`. It compares raw and MAD-prepared inputs. These scripts do not alter the correction implementation. The 5 MB feature-level p-value sample is regenerated by the first script rather than duplicated in this manuscript checkout; aggregate and seed-level results are supplied.

The identity-retrieval exports retain the original query-weighted point estimates and correct the 2,000 paired identity-bootstrap draws to weight each resampled identity by its eligible query count. The original identity-weighted intervals are retained in explicitly named `_before_query_weighting` audit files; they are not the current uncertainty estimates. Clinical per-identity sufficient statistics were recovered exactly from the archived bootstrap series and checked against every original draw and the raw matrix, without exporting identity rows; for the WiNN 0.1.6 refresh they were read directly from the new derivative run, which kept them on the analysis machine. `batchcorr_identity_retrieval_paired.csv` is a separate new identity-balanced 5,000-draw sensitivity analysis, with a different estimand; it is not substituted into the manuscript’s frozen endpoint.

Prepared design CSVs are aggregate audits of the benchmark’s actual prepared metadata. No private clinical biological identifiers or raw clinical matrices are included. Clinical phenotypes are unavailable; their balance was not audited. Same-feature effect summaries compare with raw input descriptively and do not treat features as independent biological replicates.

The benchmark and targeted implementation checks use the frozen WiNN 0.1.6 build (source tarball SHA-256 e40a2c3fd709f11a456ac3721379da3549e89c619e5a164743e203fe1e9be7ab), which corrects the mgcv smoother calls that made earlier versions fall back to LOESS; this is the 0.1.6 release used throughout the manuscript. The package-upgrade run recomputed only WiNN outputs, while retaining Raw, baseline, comparator and design-audit outputs from its validated input release. The subsequent QC-RFSC chronology correction separately refitted all five empirical datasets and ten simulation seeds; other comparator outputs remain unchanged. Current integration and uncertainty checks are recorded in `qcrfsc_bootstrap_validation.csv`, `qcrfsc_bootstrap_pairing_validation.csv` and `qcrfsc_chronology_matrix_audit.csv`. Native statTarget preprocessing treats nonpositive values as missing, applies `FilterMV` and performs KNN imputation using the full input matrix. Held-out references are excluded from forest training, training-QC abundance scaling and parameter selection; they are not excluded from this native preprocessing. The aggregate input audit found 48,820 zero entries in WaveICA (2,742 in training QCs, 587 in held-out references and 45,491 in study injections), with no negative or preexisting missing values. Native `FilterMV` removes nine WaveICA features, leaving 47,912 missing entries to be imputed (2,635 in training QCs, 573 in held-out references and 44,704 in study injections). The other four empirical datasets and all ten simulation inputs contain no zero, negative or nonfinite entries, and have no missing entries after native filtering. `qcrfsc_preprocessing_input_audit.csv` records these counts and input hashes without sample identifiers; `scripts/benchmark_revision/audit_qcrfsc_preprocessing_inputs.R` reproduces the audit.
