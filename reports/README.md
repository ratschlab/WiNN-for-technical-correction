# Suitability reports

The reports in this directory document why each deposited public matrix was accepted for benchmarking and record its limitations. Sacurine and WaveICA reports are regenerated by their preprocessing scripts. The BatchCorr Set 1 report records the audit of `set.1` and `set.1.Y` at the pinned source commit.

MTBLS146 and the oral-cavity study are retained as negative audits. Both lack a deposited, minimally processed injection-level feature matrix, so neither was taken forward and no raw spectra were downloaded.

No correction method should be run on a new dataset until an equivalent audit confirms a minimally processed feature matrix, reliable batch and acquisition order, identifiable controls, and usable biological labels.
