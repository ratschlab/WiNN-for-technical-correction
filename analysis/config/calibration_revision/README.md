# Permutation drift-gate rerun

This revision changes only WiNN's drift selection: the Ljung–Box statistic is calibrated against 999 joint-column permutations using a maxT reference and the plus-one correction. The default permutation seed is 104729. Adjusted probabilities are compared directly with the selected threshold (0.05 in fixed mode; 0.01, 0.05 or 0.10 in the unchanged tuning grid). They are not passed through BH again. The batch ANOVA gate, MAD preparation, detrending, PQN, input matrices, candidate grid, evaluation definitions, comparator fits and bootstrap/permutation draws remain fixed.

The auto-mode search has 36 nominal combinations: one Ljung–Box test, two smoothers, three drift thresholds, three batch thresholds and two normalizations. Some threshold combinations share a cached result. Historical manifest entries claiming 72 combinations for five datasets were descriptive errors; the previous and current adapters both request only Ljung–Box. Correcting those entries does not alter the search.

The package build is pinned in `package/frozen_package.json`. It is a development build, version 0.1.7.9999. The previous specification is retained here as `previous_frozen_package.json`. The imported downstream evaluation code came from the validated November 2026 derivative release; its original source hashes are in `derivative_source_provenance.csv`.

## Execution

Use an isolated release directory with the canonical inputs and the R environment specified by the Euler scripts. Do not overwrite the previous release. The primary launcher is `analysis/euler/submit_winn_rerun.sh`. It runs Raw as an input/evaluation check and all three WiNN modes, including primary benchmarks, repeated simulations, reference splits, cumulative ablations and partial confounding. The 480 correction/task bundles exclude comparator fits. Reference evaluators can start once their four corresponding fit tasks have completed. Their 8 GB, four-hour allocation retains more than six times the observed primary-evaluation peak memory and more than seven times its elapsed time; the concurrency cap is 60. These scheduling changes do not alter the analysis.

Submit the downstream chain with `bash analysis/euler/submit_derivative_rerun.sh PRIMARY_JOB_ID AGGREGATE_JOB_ID`, after staging the previous aggregate, derivative exports and frozen matrices in the paths checked by that launcher.

The `derivative_stage.sbatch` job runs after the primary array. It stages the 18 new WiNN matrices and verifies the exact hashes of 36 historical Raw/comparator matrices. `derivative_empirical.sbatch` and `derivative_lobo.sbatch` run after staging. They retain the prespecified 2,000 bootstrap draws and, where applicable, 5,000 label permutations. Existing support for partial reruns is used for WaveICA, BatchCorr Set 1, clinical FIA-MS and every leave-one-batch-out bootstrap. MTBLS79 and Sacurine evaluate all frozen matrices; unchanged comparator values are checked before their exact prior CSV rows are restored. Neither operation refits a comparator.

After correction aggregation, `derivative_simulation.sbatch` splices the new WiNN rows into the previous aggregate using `splice_winn_rerun.R`, restores historical Raw timings and all comparator rows, refreshes ablation-stage differences and audits the complete rerun. It then evaluates the ten simulation seeds with the frozen bootstrap draws. `derivative_aggregate.sbatch` runs after every derivative job and validates the final tables and matrix hashes.

`refresh_winn_selection_provenance.R` updates only the descriptive version and calibration fields in WiNN selection records inherited from the old configuration manifest. It records before/after hashes and never changes fitted matrices, scores or selected candidates. Production run manifests independently record the installed package build.

The empirical baseline evaluator accepts existing baseline fits and saved baseline bootstrap draws. Recompute query-weighted retrieval from the new per-identity scores; do not reuse old WiNN scores. `audit_revision_derivative_effects.R` updates matched-feature effect summaries and the clinical batch-R² bootstrap audit from the regenerated derivative exports. `refresh_identity_sensitivity.R` separately refreshes the optional identity-balanced BatchCorr sensitivity using its original seed 20261027 and 5,000 paired draws. It is not substituted for the query-weighted primary endpoint. The old-input replay reproduces all 27 sensitivity rows exactly, and all 18 comparator rows remain exact. The publication staging script retains every non-WiNN scientific row from the preceding manuscript inputs.

## Validation boundaries

Fixed-segment familywise error control assumes joint exchangeability of true-null feature columns under the shared within-segment permutations. Zero autocorrelation alone does not imply this. Data-dependent segmentation, QC tuning, multiple segments jointly and scheduled biological structure require separate empirical interpretation.

Independent gate validation uses the frozen source functions and paired datasets for old/new algorithms. The matching `validation_helper_body_sha256.csv` and `production_helper_body_sha256.csv` verify that the validated functions match the production package. `primary_selected_parameter_preflight.csv` records the actual calibration and selected drift/batch thresholds from all 18 primary WiNN fits. Its final aggregate results and session information are retained with the revision evidence; temporary scheduler shards are not publication inputs.

Restricted clinical inputs and identity-level files remain outside the public repository. Public clinical outputs are aggregate estimates or resampling statistics without direct identities. No corrected matrices are included in the manuscript bundle.
