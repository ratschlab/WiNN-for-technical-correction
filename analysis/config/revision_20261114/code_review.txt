Reproducibility fix
The partial-confounding runner previously used abbreviated intensity-hash
column names; R partially matched diagnostic-only columns. The v3 contract
instead gates the log matrices before exponentiation, because intensity
rounding can differ across platforms. The runner now verifies exact named
log-hash fields and the schema/digit count. Regression tests reject corrupted
or absent authoritative fields and duplicate rows, and accept changed
intensity diagnostics. This fixes preflight portability, not stored results.

Interpretation
The confounding design is a controlled stress experiment, not a comprehensive
realistic biological model. Maximum batch alignment retains one mixed plate;
it is not complete confounding. Strong symmetric signals in 450 independent
simulated samples explain high power in the randomized setting. Recovery uses
the realized ground-truth coefficient on the same log1p scale. Seed-level
empirical_fdr is a false-discovery proportion; its mean estimates FDR.
The reproduced all-null drift results show that the nominal 5% BH threshold
does not ensure 5% experiment-level FDR for these short-segment Ljung-Box
p-values. Reproduced MAD/PQN results confirm attenuation of rare and widespread
coordinated responses, without technical artifacts.

QC-RFSC
The corrected adapter's empirical points have no rerun bootstrap/permutation
uncertainty. Earlier-adapter uncertainty is not transferable. WaveICA's point
uses the same 568 study samples; MTBLS79's generic biological point uses 134
study injections, unlike the 20 sample-collapsed means in the main figure.
It must not be substituted. The saved corrected matrix and prepared public
input were recovered from Euler and evaluated with the exact sample-mean
procedure. The comparable RFSC point is 18.928817833772% batch variance and
43.6730579019026% biological-group variance, using 134 injections and 20 sample
means respectively. Raw endpoints reproduce the manuscript points within 1e-8;
the batch endpoint reproduces the archived corrected RFSC result within 1e-8.
No correction or uncertainty analysis was refitted. Input SHA-256 values and
a reproducible evaluator accompany the new aggregate result.
The clinical corrected RFSC CV 16.8798% and residual
drift 11.6661% are above primary WiNN 12.29% and 7.5728%; the claim of lowest
values among the seven primary methods is supported.
The archived QC-RLSC diagnosis reports 182.8436% held-out CV and 266,216 warnings
with qcrlscR 0.1.3 on MTBLS79. Sparse training-QC coverage and extrapolation
support a layout/configuration-specific instability diagnosis.

Limits
This is not a repeat of every large correction, bootstrap, or permutation run.
The default local R library lacked statTarget; its integration test was
therefore run successfully with the frozen 1.38.0 version on Euler. Archived
225 integration checks also pass the publication validator.
Clinical row-level data are restricted. Sample-level bootstrap clustering
cannot be assumed to establish patient-level independence for longitudinal
samples. Package algorithm and analyzed version remain unchanged; GitHub
package documentation revision d9e81b5 records corrected assumptions and a
randomized illustrative biological signal.
